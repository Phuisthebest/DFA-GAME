    How to play

    • Each round shows a regular expression. Two scientists each draw a DFA for it. One machine is correct. The other is wrong in exactly one place.
    • The arrow with no source points at the start state. A double circle marks an accepting state.
    • When the dead state is not drawn: if the current state has no edge for the symbol being read, the machine rejects.
    • Trap types: an edge to the wrong state, a missing edge, an extra edge, two swapped labels, a wrong label, a misplaced double circle.
    • On Shuffled, each scientist names and arranges the states their own way. Two different pictures can still be the same language.
    • You can type a word and watch both machines run. A machine only tells you whether it accepts or rejects. Whether the word belongs to the language is for you to work out from the expression.
    • Score: 100, 150 or 200 depending on trap level. Each consecutive correct pick adds 25 (up to 100). A round with no test run adds 50.
    • Endless mode has no round limit. One wrong pick ends the game. Your best score and rounds survived are saved as a separate record.
    • Shortcuts: 1 picks the left board, 2 the right board, Enter goes to the next round.
